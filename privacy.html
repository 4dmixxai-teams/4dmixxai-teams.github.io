개인정보처리방침

재난이슈룸 · 최종 수정일 2026년 9월 12일

1. 이 방침이 적용되는 범위

재난이슈룸이 운영하는 유튜브 영상 업로드 자동화 프로그램(이하 "이 프로그램")과 이 웹사이트에 적용됩니다.

2. 수집하는 정보

이 프로그램은 일반 이용자의 개인정보를 수집하지 않습니다. 이용자가 로그인하거나 정보를 입력하는 기능이 없습니다.

이 프로그램을 사용하는 운영자 본인에 대해서만, 유튜브에 영상을 올리기 위해 다음을 처리합니다.

  • 운영자가 직접 발급해 설정한 구글 OAuth 인증 토큰

이 토큰은 운영자가 소유한 유튜브 채널에 영상을 올리는 용도로만 쓰이며, 운영자의 저장소 비밀 설정(GitHub Secrets)에 보관됩니다. 제3자에게 제공하거나 다른 목적으로 사용하지 않습니다.

3. 사용하는 구글 API 와 권한

이 프로그램은 YouTube Data API v3 를 사용하며, 요청하는 권한은 다음 하나뿐입니다.

  • https://www.googleapis.com/auth/youtube.upload — 운영자 채널에 영상 업로드

영상 시청 기록, 구독 정보, 댓글 등 다른 정보에는 접근하지 않습니다.

구글 사용자 데이터의 사용은 Google API 서비스 사용자 데이터 정책을 따르며, 제한적 사용 요건을 준수합니다.

4. 보관과 삭제

인증 토큰은 운영자가 직접 삭제할 때까지 보관됩니다. 운영자는 구글 계정의 제3자 앱 및 서비스 화면에서 언제든지 이 프로그램의 접근 권한을 해제할 수 있고, 해제하면 토큰은 즉시 무효가 됩니다.

5. 제3자 제공

수집한 정보를 제3자에게 판매·대여·제공하지 않습니다. 영상이 업로드되는 유튜브는 운영자 본인의 채널입니다.

6. 쿠키와 추적

이 웹사이트는 쿠키를 사용하지 않고, 방문자를 추적하지 않으며, 광고를 싣지 않습니다.

7. 아동의 개인정보

이 프로그램은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

8. 방침의 변경

내용이 바뀌면 이 페이지의 최종 수정일을 함께 갱신합니다.
